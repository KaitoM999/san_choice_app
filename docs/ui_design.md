# 画面設計 (UI Design)

## 共通コンポーネント (Common Components)
全画面で共通して使うパーツの定義。
- メインカラー: 保留
- **3択ボタン:** 角丸、タップ時に正誤アニメーション
- **音声ボタン:** スピーカーアイコン、再生中は色が変わる

---

## 1. ホーム画面 (Home)
- **ヘッダー:** アプリロゴ「3択ロース」
- **中央:** 「学習を始める」の大きなボタン
- **フッター:** 設定アイコン（リセット機能への入り口）

## 2. クイズブロック選択画面 (Block Selection)
- **上部:** - 出題方向トグル（[日→越] [越→日]）
  - 全リセットボタン（ゴミ箱アイコン）
- **リスト部:** - 1〜200のカード形式リスト
  - カード内容：ブロック番号、前回のスコア（例：★★☆ 4/6）
- **アクション:** カードタップで「クイズ画面」へ遷移

## 3. クイズ画面 (Quiz Main)
- **上部:** 進捗インジケータ（今 3/6 問目）
- **中央:** 問題単語（大きく表示）
- **下部:** 3つの選択肢ボタン（横幅いっぱい）
- **特殊操作:** 左上の「×」ボタンで中止ダイアログ表示

## 4. 回答・解説表示 (Answer Detail)
※回答後にクイズ画面が切り替わる、またはオーバーレイで表示
- **正誤アニメーション:** 画面中央に大きく「○」か「×」
- **詳細情報:** - 単語の訳、品詞
  - 音声再生ボタン
  - 例文、例文の訳、例文の音声ボタン
- **アクション:** 「次へ」ボタンで次の問題へ

## 5. 結果発表画面 (Result)
- **中央:** - スコア（例：6 / 6）
  - ランクに応じたメッセージ（Perfect! / Good / Try Again!）
- **アクション:** - 「もう一度挑戦」ボタン
  - 「ブロック選択に戻る」ボタン
