# 画面設計 (UI Design)

## 共通コンポーネント (Common Components)
全画面を通じて統一されたブランド体験を提供します。
- **背景 (SnowyBackground):** 深紅（#8B0000）の背景に、アニメーションする雪の結晶が舞う演出。
- **フォント:** `GoogleFonts.mPlus1p` および `GoogleFonts.notoSansJp` を使用し、親しみやすさと視認性を両立。
- **3択ボタン:** 角丸（BorderRadius: 30）、タップ時に正誤に応じた色変化（緑/赤）。

---

## 1. ホーム画面 (Home)
アプリのポータル。世界観の提示と言語選択を行います。
- **ヘッダー:** 言語選択ドロップダウン（国旗アイコン付き）。
- **メイン:** 中央に大きく「3択ロース」のタイトルと、浮遊アニメーションするロースちゃんの画像。
- **ナビゲーション:** - 「学習を始める」：ブロック選択へ
  - 「単語一覧」：辞書機能へ
  - 「キャラクター紹介」：ストーリー背景へ
- **広告:** 画面下部にバナー広告を表示。

## 2. クイズブロック選択画面 (Block Selection)
学習の進捗を確認し、挑戦する範囲を選ぶ画面。
- **上部:** 出題方向トグル（[日→外] [外→日]）。
- **リスト:** 1〜200のカード形式リスト。
  - カード内容：ブロック番号、前回スコア（例：5 / 6）、未挑戦時のギフトアイコン（🎁）。
- **アクション:** カードタップでクイズ画面へ遷移。

## 3. クイズ画面 (Quiz Main)
メインの学習体験。
- **上部:** ステータスバー（現在の言語・ブロック）と進捗ドット。
- **中央:** - キャラクター（ロースちゃん）：解答前は考えるポーズ、解答後は正誤アクション。
  - 問題文：大きく表示。
- **下部:** 3つの選択肢ボタン。
- **解答後:** 各ボタンをタップすることで、詳細情報（品詞・例文・音声再生ボタン）が下方向にアコーディオン展開される。

## 4. 単語一覧画面 (Word List)
復習用の辞書機能。
- **リスト:** その言語の全単語をスクロール表示。
- **詳細:** 各単語に品詞、例文、例文訳を併記し、右側にTTS音声再生ボタンを配置。

## 5. キャラクター紹介画面 (Character Intro)
世界観を深掘りするファン向けの画面。
- **構成:** キャラクター画像、名前、役割（役職）、そして詳細なプロフィールテキスト。
- **演出:** カード形式のレイアウトで読みやすさを重視。

## 6. リザルト画面 (Result)
1セッションの締めくくり。
- **スコア表示:** 「○ / 6」を大きく表示。
- **演出:** スコアに応じたロースちゃんのリアクション画像。
- **格言:** 画面下部に「ターキー博士」からのメッセージボードを表示。
- **広告:** この画面へ遷移する直前にインタースティシャル広告を挿入。
