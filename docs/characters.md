# オリジナルキャラクター仕様書 (Characters)

## 1. キャラクター概要
アプリ「3択ロース」の公式ナビゲーター。

### **サンタクロース：ニョッキ (Nyokki)**
- **役割:** クイズの出題、正解時の祝福。
- **見た目:** 超小柄、3束のヒゲ、丸ボタンの衣装。
- **カラー:** #E53935 (サンタレッド)

### **トナカイ：カルビ (Karubi)**
- **役割:** サンタの移動手段、アプリのアイコン。
- **見た目:** 丸っこい体、3股のツノ、色が変わる鼻。
- **カラー:** #795548 (トナカイブラウン)

---

## 2. 表情・アクションリスト (States & Animations)
アプリの状況に合わせて、キャラクターがどう動くかを定義します。

| 状況 (State) | サンタ：ニョッキのアクション | トナカイ：カルビのアクション | 鼻の色 |
| :--- | :--- | :--- | :--- |
| **通常時 (Idle)** | ニコニコして手を振る | まばたきをする | 赤 |
| **クイズ出題中** | 問題を指差す | ツノを少し傾けて考える | 黄色 |
| **正解！ (Correct)** | ジャンプしてバンザイ！ | 嬉しそうに足踏み | 赤 (点滅) |
| **不正解... (Incorrect)** | ズッコケる、または涙ぐむ | 首を横に振る、またはガックリ | 青 |
| **結果発表 (満点)** | 胴上げされる | サンタを胴上げする | 七色 |
| **結果発表 (低得点)** | 「次は頑張ろう」と励ます | 寄り添って慰める | 青 |
