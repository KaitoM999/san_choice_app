# コンセプト・要件定義：3択ロース (San Choice App)

## 1. アプリ概要
「2択では物足りない、4択では多すぎる」という学習者の心理に寄り添った、テンポ良く学べる3択形式の単語クイズアプリ。

## 2. ターゲット
- 語学初級者（まずはベトナム語からスタート）
- 効率的に、かつ達成感を感じながら語彙を増やしたい学習者

## 3. 特徴
- **絶妙な難易度:** 2択より手応えがあり、4択よりも心理的ハードルが低い「3択」に特化。
- **リッチなフィードバック:** 単なる正誤判定だけでなく、全ての選択肢に対して詳細情報（訳・品詞・音声・例文）を提供。

## 4. 主な機能

### 4.1 クイズ形式
- **出題パターン:**
  - 日本語 → ベトナム語（ターゲット言語）
  - ベトナム語（ターゲット言語）→ 日本語
- **1問ごとの詳細表示:**
  回答後、3つの選択肢それぞれについて以下の情報を表示・操作可能とする。
  - 訳、品詞、単語音声（再生ボタン）
  - 例文、例文の訳、例文の音声（再生ボタン）

### 4.2 学習ボリュームと構成
- **学習単位（ブロック）:** 1回あたり「6問」の固定構成。
- **目標設定:** 全200ブロック（計1,200単語）を段階的に攻略。
- **採点:** 各ブロック6点満点で評価。

### 4.3 学習管理
- **履歴保持:** 各ブロックの「前回の点数」を記録・表示。
- **リセット機能:** 記録の全件リセットボタンを搭載。

## 5. 将来の拡張性
- **多言語展開:** ロシア語など、他の言語へのスムーズな切り替え。
- **データ管理:** 1,200単語以上の追加や、ユーザー独自の単語帳作成機能（検討事項）。
