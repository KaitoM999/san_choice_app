# コンセプト・要件定義：3択ロース (San Choice App)

## 1. アプリ概要
「2択では物足りない、4択では多すぎる」という学習者の心理に寄り添った、テンポ良く学べる3択形式の語学学習アプリ。クリスマスと「サンタ・ロース」を掛け合わせた独特な世界観の中で、効率的な語彙習得を目指します。

## 2. ターゲット
- 語学初級者（多言語対応：ベトナム語、中国語、韓国語、ロシア語、フランス語、ドイツ語）
- 効率的に、かつ達成感を感じながら語彙を増やしたい学習者
- シュールなストーリーやキャラクター設定を楽しみながら継続したい人

## 3. 特徴・強み
- **絶妙な3択リズム:** 心理的ハードルを下げつつ、確実な記憶定着を狙う形式。
- **リッチなフィードバック:** 回答後、すべての選択肢について「品詞・例文・翻訳・音声」をその場で確認可能。
- **多言語対応設計:** `LanguageConfig` による一元管理。TTS（音声合成）も各言語のネイティブコードに対応。
- **没入感のある演出:** 全画面に舞う雪の演出（`SnowyBackground`）と、スコアに連動したキャラクターアクション。

## 4. 主な機能

### 4.1 クイズシステム
- **双方向出題:** 「日本語 → 外国語」および「外国語 → 日本語」の切り替えが可能。
- **カード展開式詳細表示:** 回答後、3つの選択肢それぞれをタップすることで詳細情報を表示・操作可能。
- **TTS（音声合成）:** FlutterTtsを用いた、単語および例文の即時発音再生。

### 4.2 学習構成
- **6問1ブロック制:** 短い時間で集中して取り組める学習単位。
- **進捗管理:** `SharedPreferences` を利用し、各ブロックの「最高スコア」を永続化。
- **言語切り替え:** ホーム画面のドロップダウンから即座にターゲット言語を変更可能。

### 4.3 収益化・外部連携
- **広告実装:** `Google Mobile Ads` を統合。バナー広告および、リザルト移行時のインタースティシャル広告。
- **CI/CD:** GitHub Actionsによる自動テスト環境を構築。

## 5. キャラクター・設定 (Lore)
- **ロースちゃん:** 主人公。行方不明の恩師ターキー博士を探す見習いサンタ。
- **ターキー博士:** 去年12月24日に他界しているが、ロースちゃんはその事実を知らずに探し続けている。リザルト画面で格言を授ける。
- **トナカイくん:** 普段は可愛いが、怒ると（そしてクリスマスの日も）肉食になる相棒。
- **クロスさん:** ロースちゃんの母。実は元・一流の3択ロース。

## 6. 技術仕様
- **言語/フレームワーク:** Dart / Flutter
- **データ管理:** JSONファイル（言語別単語データ）、SharedPreferences（ユーザー成績）
- **品質管理:** flutter_testによるロジックテスト、GitHub Actionsによる継続的インテグレーション。
- **開発フロー:** Git Flow（main / develop / featureブランチ）に基づいたIssue管理。
