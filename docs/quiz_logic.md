# クイズロジック仕様書 (Quiz Logic)

このドキュメントでは、1ブロック（6問）のクイズ生成アルゴリズムと、ユーザー体験のフローを定義します。

---

## 1. クイズ生成アルゴリズム (Generation)

ブロック選択後、`QuizScreen` の初期化時に以下の手順で6問の問題セットが生成されます。

1. **データのフィルタリング**:
   - 選択された言語の全単語リストから、指定されたブロック番号に該当する6つの単語（例：ブロック1なら1〜6番）を抽出する。
2. **正解の決定**:
   - 6つの単語それぞれを「問題（Question）」として設定する。
3. **ダミー選択肢の選出**:
   - **全単語リスト**（ブロック内限定ではなく、その言語の全データ）から、正解以外の単語をランダムに2つ選出する。
   - これにより、ブロックをまたいだ広範な語彙が選択肢に現れ、難易度を適切に保つ。
4. **シャッフル**:
   - 正解1つとダミー2つの計3つをシャッフルし、`correctIndex`（0, 1, 2）を決定する。
5. **双方向出題の適用**:
   - ユーザー設定に基づき、「日本語 → 外国語」または「外国語 → 日本語」に表示を切り替える。

---

## 2. セッションフロー (Quiz Flow)

### ① 出題フェーズ (Question)
- **表示**: 進捗バー（6個のドット）、問題文、3つの選択肢ボタン。
- **演出**: 背景に雪が舞い、ロースちゃんが「うーん」と悩むポーズで待機。
- **音声**: TTS（音声合成）により問題文の音が自動再生される。

### ② 解答フェーズ (Answer)
- **判定**: ユーザーがボタンをタップ。
- **即時フィードバック**:
  - 正解：ボタンが緑色になり、ロースちゃんが「正解！」のアクション。
  - 不正解：選択したボタンが赤色になり、正解のボタンが自動的に強調される。

### ③ 詳細解説フェーズ (Deep Dive)
- **カード展開**: 正誤判定後、各選択肢のカードをタップすることで、以下の詳細情報が展開される。
  - 単語の品詞
  - 例文および例文の訳
  - 単語・例文それぞれの個別音声再生ボタン
- **次へ**: 納得したタイミングで「次の問題へ」ボタンを押して進行。

### ④ 終了・リザルトフェーズ (Result)
- **広告挿入**: 6問終了後、リザルト画面へ遷移する直前に「インタースティシャル広告」を表示（※準備ができている場合）。
- **スコア記録**: `SharedPreferences` にそのブロックの最高スコアを保存。
- **演出**: スコアに応じて、ターキー博士から魂の格言（全6種類以上）が授与される。

---

## 3. 特殊ロジック

- **音声合成 (TTS)**: `flutter_tts` を使用し、各言語（`vi-VN`, `de-DE` 等）に応じた最適なエンジンで再生する。
- **画像・テキスト切り替え**: 演出上、テキストの代わりにキャラクター画像を表示して考える間を作るなど、視覚的な楽しさを優先する。
